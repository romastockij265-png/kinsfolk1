# Журнал изменений
## 0.0.1 — этап 0
Ядро, роутер, журнал ошибок, экран «О программе». Без входа и чатов.

## 0.1.0 — этап 1
Регистрация (email+пароль+код), вход паролем, вход по коду, сброс пароля, смена пароля, выход / выход везде, удаление аккаунта, профиль (имя, @username, фото). Версия вынесена в js/core/version.js.

## 0.1.1
Вход упрощён: только почта → 6-значный код (без паролей). Новый аккаунт создаётся сам при первом входе. Убраны регистрация с паролем, сброс и смена пароля.

## 0.1.2
Сборка Android-приложения (APK) через GitHub Actions + Capacitor: docs/APK.md, docs/build-apk.yml.txt, assets/ (значки, ключ подписи).

## 0.1.3
На экране входа добавлена ссылка «Журнал ошибок» (чтобы видеть причину ошибки до входа).

## 0.1.4
Ошибка «Error sending confirmation email (500)» теперь показывается как «Не удалось отправить письмо», а не «Нет сети». Сеть определяется только при реальном обрыве.

## 0.1.5
Экран кода: 8 ячеек и кнопка «Подтвердить» — работает и с 6-, и с 8-значным кодом (Supabase присылает код разной длины).

## 0.1.6
Исправлено: при ошибке запуска вместо экрана «Повторить» показывался экран «О программе» (гонка маршрутов). Экран «Повторить» теперь с кнопкой «Журнал ошибок».
- 0.1.6: исправлена причина «вместо ошибки показывается О программе»: функция в параметрах маршрута не копировалась в историю браузера (DataCloneError).

## 0.1.7
Если таблица profiles не создана (не выполнен SQL), экран ошибки говорит об этом прямо. На экране «Не удалось загрузить данные» добавлена кнопка «Выйти».
