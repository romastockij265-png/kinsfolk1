# Как получить приложение Kinsfolk (APK) — по порядку
## Один раз: подготовка
1. Загрузите zip с этапа в репозиторий (как обычно) — в нём теперь есть папка assets/ и файл docs/build-apk.yml.txt.
2. GitHub → ваш репозиторий → **Settings → Actions → General** → внизу **Workflow permissions** → выберите **Read and write permissions** → **Save**.
3. Создайте файл сборки: **Add file → Create new file**. В поле имени введите `.github/workflows/build-apk.yml` (слэши создадут папки). Откройте docs/build-apk.yml.txt, нажмите Copy raw file, вставьте весь текст в большое поле → **Commit changes**.
## Каждый раз, когда нужна новая версия приложения
1. Вкладка **Actions** → слева **Build APK** → справа **Run workflow** → зелёная **Run workflow**.
2. Подождите 5–10 минут: жёлтый кружок станет зелёной галочкой. Красный крестик — откройте запуск, скопируйте текст ошибки из красного шага и пришлите мне.
3. Вкладка **Code** → справа **Releases** → самый верхний → файл **Kinsfolk.apk** → скачайте.
4. Откройте скачанный файл. Телефон попросит разрешить установку из этого источника — разрешите. Если Play Protect ругается — **Всё равно установить**.
## Важно
- Все сборки подписаны одним и тем же ключом (assets/debug.keystore), поэтому новая версия ставится поверх старой без удаления. Ключ лежит в репозитории открыто — для компании друзей это нормально, но не публикуйте приложение в Google Play с этим ключом.
- Сайт в браузере продолжает работать; приложение внутри — тот же сайт, поэтому после загрузки новых файлов нужно заново запустить сборку.
- На iPhone приложение так не собрать (нужен Mac и платный аккаунт Apple).
